Ensemble Stacking Classifier

A classic machine learning ensemble combining three gradient-boosted and tree-based classifiers via a stacking meta-learner for robust, interpretable risk classification.

Base Learner Architecture

The ensemble stacks three independent classifiers trained on the same 19-feature vector, each contributing complementary signal to the meta-learner:

  • LightGBM — Gradient-boosted trees optimised with Optuna hyperparameter search. Excellent at capturing non-linear feature interactions across sparse code-metric distributions.
  • XGBoost — Extreme gradient boosting with histogram-based splits. Regularised with L1/L2 to prevent overfitting on minority classes.
  • Extra Trees (ET) — Extremely randomised trees providing high variance diversity from the other two learners, improving out-of-bag generalisation.

A Logistic Regression meta-learner combines the out-of-fold probability predictions from each base learner via cross-validated stacking, producing the final 3-class probability output (Clean / Moderate Risk / High Risk).

Training Pipeline

  • Data source: 19-feature vector extracted by the base static analyser (LOC, CC, memory leak count, unsafe function count, recursion count, etc.)
  • Class balancing: SMOTE (Synthetic Minority Over-sampling Technique) applied on the training split to handle imbalanced Clean / Moderate / High Risk class distributions.
  • Hyperparameter tuning: LightGBM tuned via Optuna with 50 trials optimising the weighted F1-score.
  • Cross-validation: 5-fold stratified CV used for both Optuna and stacking out-of-fold predictions.
  • Output file: model.pkl — scikit-learn Pipeline object (scaler + stacking ensemble).

When to Use the Ensemble

The Ensemble model is the most interpretable of the four models. Each base learner produces per-class probabilities that can be individually inspected. It performs well on code with straightforward metric signatures where the features are good linear/tree-node separators. It is the fastest at inference time with no GPU requirement.

Use it as a baseline reference — if the Ensemble and V3 agree but DL V1 disagrees, the DL model may be picking up on subtle non-linear patterns the trees miss, or it may be a false alarm worth investigating.
