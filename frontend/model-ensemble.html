ExtraTrees Ensemble Model

The highly-optimized, incredibly fast machine learning engine built on scikit-learn's ExtraTreesClassifier.

Technical Specifications

Accuracy: 100.0% on synthesized logic tests

Feature Vector: 21 Variables

Inference Time: < 5ms

How It Works

The ExtraTrees (Extremely Randomized Trees) model serves as IntelliReview's baseline defense. It operates by building a vast forest of decision trees—but unlike standard Random Forests, it selects the split points entirely at random for each feature. This extreme randomization significantly reduces the variance of the model, making it exceptionally robust against overfitting while maintaining blistering inference speeds.

The model relies on 21 syntactical and lexical features extracted directly from the Abstract Syntax Tree (AST), including:

  • Cyclomatic Complexity measurements mapping deeply nested loops.
  • Aggressive scans for unsafe C functions (e.g., `strcpy`, `gets`).
  • Memory block tracing tracking un-freed `malloc` instantiations.
  • Recursion depths and nesting severity indexing.

Best Use Cases

Ideal for lightning-fast validation pipelines, continuous integration (CI) webhook scans, and initial vulnerability triage. Because it does not delve deeply into path execution graphs, it is less computationally intensive than the V3/CNN architectures, giving instant feedback for surface-level memory and structural anomalies.
