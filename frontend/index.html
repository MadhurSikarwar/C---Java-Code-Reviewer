Read it the way a reviewer would.

IntelliReview follows your pointers through every branch, checks how buffers and strings are used, and watches for input that reaches a query or a shell. Then it marks the lines it is worried about.

  1. Each finding is numbered in the margin of the code and tied to its line.
  2. Each one says what is wrong and what to change, in plain words.
  3. The verdict follows the findings. The models only weigh in on how they add up.

Best on C and Java. C++ is read with a lighter touch: no pointer tracing, more guessing. Your code goes to the server you started on this machine, and nowhere else. Accepted a finding? Add // intellireview: ignore on that line.
