How the Upgrade Works

The Version 3 system represents a massive architectural shift for IntelliReview. Standard static analysis matches rules at random lines, often returning false-positives when an "If" statement prevents a crash. The V3 engine fixes this by constructing a full Control Flow Graph (CFG) simulating how data executes in runtime block-by-block.

13 New Path-Sensitive Dimensions are derived during execution mapping:

  • Pointer Lifetimes: It explicitly tracks state (Allocated, Freed, Dangling) across loop branches to catch Use-After-Free errors correctly.
  • Data Flow Analyzer (DFA): It crawls local variable mutations verifying global array bounds are not mutated infinitely via poorly defined recursion traps.
  • Complex Time Estimations: Because the execution path is mapped globally, it natively processes true Big-O scaling (O(N^2), O(log N)).

Why Use The V3 Engine?

The V3 engine is arguably the most exact tool for diagnosing raw engineering flaws in lower-level C code where manual memory allocation causes subtle execution leaks. It generates the truest representation of how your code behaves when given unpredictable user inputs across varied branches.
